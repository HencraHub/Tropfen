# ASSET-PROMPTS

Ein Prompt je Bildteil aus `assets/manifest.json`. Der Stilblock ist bei allen identisch. Erzeugte Dateien werden unter dem Pfad in `file` abgelegt; ohne Datei nutzt das Spiel den Rückfall aus dem Code.

## Stilblock

Stil (für jedes Teil identisch): Flaches, freigestelltes Bastelteil für ein Papp-Diorama, wie mit Schere und Kleber von Hand gemacht: Pappe, Kraftpapier, Tonpapier, Alufolie, Watte. Sichtbare Wellpappkanten, leichte Papierfaser, Tintenkontur (dunkelbraun, leicht wackelig), weiche Schreibtischlampen-Beleuchtung von schräg oben links mit deutlichem Kontaktschatten nur wenn ein Boden gezeigt wird. Palette: Pappe #c9a76b, Pappe dunkel #a37f47, Kraftpapier #e8d6ad, Papierweiß #f6f0e1, Folienblau #5aa9e6, Glasperle #a9dcff, Moos #7fa650, Tinte #2b2320, Stempelrot #b5382e. Frontal, orthografisch, ohne Perspektive, ohne Umgebung, Hintergrund transparent (PNG mit Alpha). Kein Fotorealismus, keine Verläufe mit Glanz, keine Schrift, kein Text, keine Wasserzeichen.

Stil (für jedes Teil identisch): Flaches, freigestelltes Bastelteil für ein Papp-Diorama, wie mit Schere und Kleber von Hand gemacht: Pappe, Kraftpapier, Tonpapier, Alufolie, Watte. Sichtbare Wellpappkanten, leichte Papierfaser, Tintenkontur (dunkelbraun, leicht wackelig), weiche Schreibtischlampen-Beleuchtung von schräg oben links mit deutlichem Kontaktschatten nur wenn ein Boden gezeigt wird. Palette: Pappe #c9a76b, Pappe dunkel #a37f47, Kraftpapier #e8d6ad, Papierweiß #f6f0e1, Folienblau #5aa9e6, Glasperle #a9dcff, Moos #7fa650, Tinte #2b2320, Stempelrot #b5382e. Frontal, orthografisch, ohne Perspektive, ohne Umgebung, Hintergrund transparent (PNG mit Alpha). Kein Fotorealismus, keine Verläufe mit Glanz, keine Schrift, kein Text, keine Wasserzeichen.
